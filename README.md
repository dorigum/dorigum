## 📌 My Working Style

- 📝 기능을 만들기 전에 목적과 사용자 흐름을 먼저 정리해요.
- 🧩 작은 단위로 구현하고 바로 확인해요.

- 🌱 완벽하진 않아도 매일 조금씩 나아지는 개발자가 되고 싶어요.
